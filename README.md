# Household Chores

Учебное приложение для управления домашними обязанностями одной семьи на Django.

Проект создаётся в рамках Homework 1: AI-Native Developer Workflow курса AI Dev Tools Zoomcamp от DataTalks.Club.

## Основные функции

1. **Участники семьи:** добавление людей по имени, общий доступ без регистрации и отдельных аккаунтов.
2. **Управление делами:** создание дела с названием, ручным назначением ответственного, датой и временем выполнения.
3. **Повторение по расписанию:** ежедневные и еженедельные дела. Каждый повтор создаёт отдельное дело; невыполненные предыдущие сохраняются как просроченные.
4. **Общий список и выполнение:** просмотр семейных дел, отметка выполнения и отображение просроченных дел.

## Локальный запуск

Для управления Python и зависимостями используется [uv](https://docs.astral.sh/uv/getting-started/installation/). Проект использует Python 3.13, Django 5.2 LTS и SQLite.

В терминале из корня репозитория выполните:

```bash
uv sync --locked
uv run python manage.py migrate
uv run python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Для остановки сервера нажмите `Ctrl+C`.

Если `uv` только что установлен, откройте новый терминал, чтобы команда стала доступна.

Проверка конфигурации:

```bash
uv run python manage.py check
```

Интерфейс Django настроен на русский язык, часовой пояс — `Europe/Moscow`. Виртуальное окружение `.venv` и локальная база `db.sqlite3` исключены из Git.

## Использование

1. Откройте страницу «Участники» и добавьте членов семьи по имени.
2. Нажмите «Новое дело», выберите ответственного, первый срок и вид повторения.
3. На главной странице используйте фильтры по состоянию и ответственному.
4. Нажмите «Готово», чтобы отметить отдельное дело выполненным.

Ежедневные и еженедельные повторы создаются командой:

```bash
uv run python manage.py generate_chore_occurrences
```

Команду следует запускать регулярно, например раз в час через планировщик задач. Для проверки на произвольную дату можно передать момент в формате ISO 8601:

```bash
uv run python manage.py generate_chore_occurrences --through 2026-09-08T20:00:00+03:00
```

Каждый наступивший повтор сохраняется отдельно. Предыдущие невыполненные дела остаются в списке как просроченные, а повторный запуск команды не создаёт дубликаты.

## Тесты

Запуск всех тестов:

```bash
uv run python manage.py test
```

Набор из 15 тестов проверяет:

- добавление и удаление участников;
- запрет удаления участника с назначенными делами;
- создание и валидацию разовых и повторяющихся дел;
- отображение просрочки, фильтрацию и отметку выполнения;
- ежедневную и еженедельную генерацию повторов;
- сохранение старых невыполненных дел;
- отсутствие дубликатов при повторном запуске генератора.

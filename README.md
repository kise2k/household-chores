# Household Chores

Учебное приложение для управления домашними обязанностями одной семьи на Django.

Проект создаётся в рамках Homework 1: AI-Native Developer Workflow курса AI Dev Tools Zoomcamp от DataTalks.Club.

## Основные функции

1. **Участники семьи:** добавление людей по имени, общий доступ без регистрации и отдельных аккаунтов.
2. **Управление делами:** создание дела с названием, ручным назначением ответственного, датой и временем выполнения.
3. **Повторение по расписанию:** ежедневные и еженедельные дела. Каждый повтор создаёт отдельное дело; невыполненные предыдущие сохраняются как просроченные.
4. **Общий список и выполнение:** просмотр семейных дел, отметка выполнения и отображение просроченных дел.

## Локальный запуск

Для управления Python и зависимостями используется [uv](https://docs.astral.sh/uv/getting-started/installation/). Проект использует Python 3.13, Django 5.2 LTS и SQLite.

В терминале из корня репозитория выполните:

```bash
uv sync --locked
uv run python manage.py migrate
uv run python manage.py runserver
```

Откройте http://127.0.0.1:8000/. На текущем этапе отображается стартовая страница Django. Для остановки сервера нажмите `Ctrl+C`.

Если `uv` только что установлен, откройте новый терминал, чтобы команда стала доступна.

Проверка конфигурации:

```bash
uv run python manage.py check
```

Интерфейс Django настроен на русский язык, часовой пояс — `Europe/Moscow`. Виртуальное окружение `.venv` и локальная база `db.sqlite3` исключены из Git.

## Подключение приложения — вопрос 3

Приложение подключается в **`settings.py`**, в списке `INSTALLED_APPS`. В этом проекте файл находится в `config/settings.py`, а добавленная строка выглядит так:

```python
'chores.apps.ChoresConfig',
```

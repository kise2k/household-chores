# План приложения для управления домашними обязанностями

## Цель

Создать на Django приложение для одной семьи, в котором можно распределять домашние обязанности вручную, задавать сроки и расписание повторений, а также отмечать выполнение.

Django используется по условию домашнего задания. Ниже собраны решения, принятые при обсуждении объёма первой версии.

## Вопросы и выбранные ответы

### 1. Приложение будет для одного домохозяйства или нескольких?

**Ответ:** для одной семьи.

### 2. Как будем распределять дела в семье?

**Ответ:** вручную — при создании дела выбираем ответственного.

### 3. Какие дела поддерживаем?

**Ответ:** разовые и повторяющиеся.

### 4. Как будут повторяться дела?

**Ответ:** по расписанию, независимо от выполнения предыдущего дела.

### 5. Нужны ли отдельные аккаунты членам семьи?

**Ответ:** без регистрации — общий список дел, участников добавляем по имени.

### 6. Как задаём срок выполнения дела?

**Ответ:** дата и время.

### 7. Какие варианты повторения нужны?

**Ответ:** ежедневно и еженедельно. Для ежедневных дел задаём время, для еженедельных — день недели и время.

### 8. Если наступил следующий повтор, а предыдущее дело ещё не выполнено, что делаем?

**Ответ:** сохраняем оба. Старое дело остаётся просроченным, новое появляется отдельно.

## Четыре основные функции первой версии

### 1. Участники семьи

- Добавление участников по имени.
- Общий доступ без регистрации и отдельных аккаунтов.
- Приложение предназначено для одной семьи.

### 2. Управление делами

- Создание дела с названием, ответственным, датой и временем выполнения.
- Ручное назначение ответственного из участников семьи.
- Поддержка разовых и повторяющихся дел.

### 3. Повторение по расписанию

- Ежедневное повторение в выбранное время.
- Еженедельное повторение в выбранный день недели и время.
- Каждый повтор создаёт отдельное дело независимо от выполнения предыдущего.
- Невыполненные предыдущие дела сохраняются как просроченные.

### 4. Общий список и выполнение

- Вся семья видит общий список дел.
- Дела можно отмечать выполненными.
- Невыполненное дело с истёкшим сроком отображается как просроченное.

## Пример работы

В семье есть участник Саша. Ему вручную назначают дело «Вынести мусор» с ежедневным повторением в 20:00. Если вчерашнее дело осталось невыполненным, следующий повтор всё равно создаёт отдельное дело. В списке сохраняются и вчерашнее просроченное дело, и новое. Каждое можно отметить выполненным отдельно.

## Краткий ответ для домашнего задания

Выбраны четыре функции: добавление участников семьи без регистрации; создание дел с ручным назначением ответственного и сроком до даты и времени; ежедневные и еженедельные повторы с сохранением невыполненных предыдущих дел; общий список с отметкой выполнения и отображением просроченных дел.

# Household Chores

Учебное приложение для управления домашними обязанностями одной семьи на Django.

Проект создаётся в рамках Homework 1: AI-Native Developer Workflow курса AI Dev Tools Zoomcamp от DataTalks.Club.

## Основные функции

1. **Участники семьи:** добавление людей по имени, общий доступ без регистрации и отдельных аккаунтов.
2. **Управление делами:** создание дела с названием, ручным назначением ответственного, датой и временем выполнения.
3. **Повторение по расписанию:** ежедневные и еженедельные дела. Каждый повтор создаёт отдельное дело; невыполненные предыдущие сохраняются как просроченные.
4. **Общий список и выполнение:** просмотр семейных дел, отметка выполнения и отображение просроченных дел.
